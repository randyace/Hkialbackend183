HKIAL port-mismatch gotcha (project-local, 2026-06-12): customer `frontend/.env.example` defaults `VITE_API_BASE_URL=http://localhost:3001/api` but `backend/hkial-api/.env` runs API on `:8000`. Running customer against local API requires explicit override to `http://localhost:8000/api`. Otherwise customer 404s on every API call. Full fix: `HKIAL/skills/hkial-setup-onboarding/SKILL.md` §5.
